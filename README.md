# Estratégia Bitcoin · site

- `index.html`: site com a Biblioteca.
- `termometro/`: Termômetro do Bitcoin. A página lê `termometro/dados.json`.
- `scripts/coleta.py`: busca os dados públicos (Coin Metrics, alternative.me, Banco Central, FRED) e calcula as notas.
- `.github/workflows/atualizar.yml`: roda a coleta todo dia às 7h17 (Brasília). Para atualizar na hora: aba **Actions** → *Atualizar termômetro* → **Run workflow**.

Conteúdo educacional; não é recomendação de investimento.
